# 🏗️ Структура проекта «Советникъ — Экспертное Бюро»

В данном файле приведена детальная структура проекта, назначение ключевых директорий и файлов, а также основные используемые технические решения.

---

## 🛠️ Технологический стек

* **Фреймворк**: React (v19) с TypeScript (v5.8).
* **Сборщик**: Vite (v6).
* **Стилизация**: Tailwind CSS (v3) + PostCSS.
* **Роутинг**: React Router DOM (v7) (клиентский роутинг с настроенным сервером Apache `.htaccess`).
* **SEO**: `react-helmet-async` (динамические теги, мета-описание, JSON-LD микроразметка).
* **Поиск**: `fuse.js` для нечеткого поиска по прайс-листу и базе знаний.
* **Иконки**: `lucide-react`.

## 🔑 Критически важные файлы и их логика

### 1. `public/.htaccess`
Позволяет серверу Apache (хостинг Reg.ru) перенаправлять все URL на `index.html`. Без этого файла при обновлении страницы `/contacts` или `/services/...` пользователь получит ошибку 404.

### 2. `vite.config.ts`
В зависимости от флага сборки (`mode === 'clone'`) меняет логику генерации `robots.txt` и `sitemap.xml`.
* **Основной режим**: Разрешает индексацию, подключает полные карты сайта.
* **Clone режим**: Запрещает индексацию (`Disallow: /`) для предотвращения склейки поисковиками основного домена с клоном `sovetnik-cno.ru`.

### 3. `src/hooks/useShadowProfile.ts`
Служит для сбора аналитического следа пользователя: откуда пришел (канал трафика), какие UTM-метки были в адресе, по каким страницам ходил и сколько времени провел на сайте. Эти данные передаются вместе со всеми отправками форм через PHP-обработчик `/send-form.php` в Telegram-чат для более глубокого понимания лида.

### 4. `src/data/constants.tsx`
Является единым источником правды для контента. Любые изменения в перечне услуг, ценах, контактах, отзывах или текстах статей должны вноситься именно сюда.
