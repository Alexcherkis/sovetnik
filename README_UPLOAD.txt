# ПАПКА ГОТОВА К ЗАГРУЗКЕ 🚀

Все файлы в этой папке (`сайт_для_загрузки`) полностью готовы к работе.

## Что делать:
1.  Выделите ВСЕ файлы в этой папке.
2.  Загрузите их в **корневую папку** вашего сайта на хостинге Reg.ru (обычно `public_html` или `www`).

## Что внутри:
*   `index.html` и папка `assets` — Сам сайт (дизайн, тексты, формы).
*   `.htaccess` — Настройка сервера (редирект 301, ускорение сайта) [Скрытый файл, может быть не виден на Mac, но он есть].
*   `send-form.php` — Отправка заявок в Telegram.
*   `sitemap.xml` — Карта сайта для Яндекса (все услуги и блог).
*   `robots.txt` — Инструкция для роботов.
*   `favicon.svg` — Иконка сайта.
*   `yandex_...html` — Файл подтверждения Вебмастера.

Больше ничего делать не нужно. Просто загрузите файлы и сайт заработает идеально.
Удачи с запуском! 📈
