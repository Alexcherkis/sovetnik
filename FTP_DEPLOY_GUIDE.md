# FTP и Deploy Guide (Бесплатно)

## Что такое FTP?
FTP (File Transfer Protocol) — протокол для загрузки файлов сайта на хостинг-сервер. Бесплатный, работает на всех хостингах.

## Бесплатный FTP-клиент: FileZilla
Скачать: https://filezilla-project.org/ (Windows/Mac/Linux)

## Шаги для деплоя через FTP:
1. **Получите FTP-данные от хостера**:
   - Хост (например: ftp.buro-sovetnik.com)
   - Логин (обычно ваш email или username)
   - Пароль (выдаёт хостер)
   - Порт: 21 (стандартный)

2. **Соберите проект**:
   Откройте терминал в папке проекта:
   ```bash
   npm install
   npm run build
   ```
   Появится папка `dist/` — это готовый сайт.

3. **Подключитесь к серверу через FileZilla**:
   - Откройте FileZilla
   - Введите FTP-данные в верхней панели
   - Нажмите "Быстрое соединение"

4. **Загрузите файлы**:
   - Локальный сайт: откройте папку `dist/`
   - Удалённый сайт: перейдите в папку `public_html/` или `www/` (корень сайта)
   - Выделите все файлы в `dist/` и перетащите на удалённый сервер

5. **Готово!** Сайт обновится через 1-2 минуты.

**Примечание для будущих развертываний:**

Для данного проекта используется только FTP‑деплой на хостинг reg.ru. Деплой через Vercel, Netlify и другие сервисы не поддерживается.


## Проверка
После деплоя проверьте:
- Сайт открывается по адресу
- Страницы услуг (`/services/category/financial`) не выдают 404
- Картинки WebP загружаются (в DevTools → Network → Img)
